# INVARIANT-001: ИНВАРИАНТ РОСТА

## Формулировка

Для системы S(t) с граничной проницаемостью и вектором метрик M(t) выполняется следующее инвариантное соотношение: **система S растёт по метрике mᵢ тогда и только тогда, когда существует положительный нетто-поток ресурсов R_net > 0, которые система использует для увеличения данной метрики.** Без положительного нетто-потока ресурсов рост невозможен длительно. Это утверждение связывает энергетическую/материальную реальность (поток ресурсов) с наблюдаемой динамикой (изменение метрик).

## Формально

**Формулировка инварианта через ресурсный баланс:**

```
Пусть Q_i(t) = ∫₀ᵗ r_i(τ) dτ — совокупный поток ресурса i за интервал [0, t].

Тогда: ∃ mⱼ(t) такая, что dmⱼ/dt > 0  ⟺  ∃ i ∈ {1..k} : (R_in,i - R_out,i) > 0

Иначе говоря, если растёт метрика, то хотя бы один из входящих потоков ресурсов 
строго превосходит выходящий поток.
```

**Расширенная форма (через накопление):**

```
Если система растёт по метрике m со скоростью dm/dt = α > 0, 
то величина энергии/вещества, необходимая для поддержания этого роста, 
должна поступать из окружения:

P_required(α, m) ≤ P_available(t)

где P_required — энергетическая или материальная стоимость роста на 1 единицу метрики,
    P_available — доступная мощность входящего ресурса.
```

**Форма через запасы:**

```
Система может расти краткосрочно за счёт исчерпания накопленных запасов,
но долгосрочный рост требует:

R_in(t) > R_out(t)  для t → ∞

То есть нетто-поток ресурсов должен оставаться положительным в долгосрочном периоде.
```

## Минимальные условия истинности

1. **Открытость системы:** система должна иметь проницаемую границу, позволяющую потокам ресурсов входить и выходить. Для замкнутой системы инвариант не применяется, потому что R_in = 0 и R_out ≤ R_stock (система может только исчерпывать внутренние запасы).

2. **Положительный нетто-поток:** R_net(t) = R_in(t) - R_out(t) > 0 для хотя бы одного типа ресурса на интервале [t₀, t₁]. Если R_net ≤ 0 для всех ресурсов, то рост метрик невозможен.

3. **Измеримость:** метрика должна быть операционально определена и измеримо связана с поступающими ресурсами. Например, рост массы связан с поступлением вещества; рост информационной ёмкости связан с поступлением данных или вычислительной мощности.

4. **Причинная связь:** между входящим потоком ресурса и ростом метрики должна существовать физическая, химическая или информационная причинная цепочка. Недостаточно только временного совпадения; должен быть механизм, который преобразует ресурс в рост.

## Максимальная область применимости

Инвариант применим ко всем типам систем, у которых:
- Есть чётко определённая граница между системой и окружением.
- Есть хотя бы одна измеримая метрика, которая может изменяться со временем.
- Существуют ресурсы, которые система может захватить из окружения.
- Время течёт линейно (системы в классической механике, а не в релятивистских условиях).

**Применимость по дисциплинам:**
- **Физика:** рост размера, массы, энергетического содержания звёзд, планет, кристаллов.
- **Биология:** рост организмов, популяций, экосистем.
- **Социология:** рост городов, организаций, государств.
- **Экономика:** экономический рост (ВНП, производство, капитал).
- **Информатика:** рост размера базы данных, объёма вычислений, количества пользователей.

**Не применимо к:**
- Квантовым системам на микроскопическом уровне (где энергия квантуется и классический баланс нарушается).
- Системам на временных шкалах, близких к квантовому масштабу времени (ℏ/E).
- Системам в поле сильной гравитации у чёрных дыр (где причинность может быть нарушена).

## Где нарушается

**Контрпример 1: Закрытая система.** Герметичный контейнер с бактериями. R_in = 0, система не получает питательные вещества извне. На начальном этапе бактерии растут за счёт внутренних запасов питательных веществ (исчерпание R_stock). Через несколько дней питательные вещества кончаются, R_stock → 0, рост прекращается. Инвариант нарушается, потому что R_in = 0, но система всё равно росла некоторое время. Разрешение: инвариант по-прежнему верен, но с уточнением: краткосрочный рост возможен за счёт запасов; долгосрочный рост требует R_in > R_out.

**Контрпример 2: Эволюция и естественный отбор.** Появление нового вида. На первый взгляд, новый вид начинает расти, но откуда берутся ресурсы? Они не «созданы», а перераспределены от других видов. Нет нового входящего потока энергии в экосистему, есть только переопределение того, как доступная энергия расходуется. Инвариант по-прежнему верен на системном уровне: рост нового вида + снижение численности старого вида = нулевой нетто-рост на уровне экосистемы.

**Контрпример 3: Информационный рост без энергетического роста.** Компьютер может увеличить объём хранимой информации (метрика) с помощью сжатия данных, не потребляя дополнительной энергии. Инвариант нарушается? Нет: энергия потребляется для вычисления (сжатия), просто она не попадает в метрику «масса». Инвариант остаётся верен, если правильно определить, какие ресурсы используются.

## Обобщения

**Обобщение 1: Компромиссы между метриками.** Система может расти по одной метрике (m₁) за счёт уменьшения другой (m₂), если ресурсы перенаправляются. Полное обобщение инварианта: система может изменять структуру вектора метрик M, но общая «стоимость» роста (в единицах ресурсов) не может превышать входящий поток.

**Обобщение 2: Сетевые эффекты.** В сетевых системах (социальные сети, интернет) рост может быть экспоненциальным, если каждый новый участник привлекает ещё больше участников. Но это не нарушает инвариант; это просто означает, что «стоимость» привлечения каждого нового участника снижается благодаря сетевым эффектам. Ресурсы используются эффективнее, но инвариант остаётся: R_net > 0 остаётся необходимым условием.

**Обобщение 3: Отрицательный рост (сжатие).** Если R_net < 0, система сжимается: метрики уменьшаются. Инвариант применим и в обратном направлении: сжатие системы происходит именно потому, что нет положительного нетто-потока ресурсов.

## Используется в

- **STEP-001:** инвариант выражает главное соотношение между ростом системы и входящими ресурсами. Это основание для перехода к STEP-002 (Рост создаёт ограничения), где показано, что растущие системы с течением времени сталкиваются с ограничениями на доступные ресурсы.

- **STEP-002 (будущий):** инвариант будет использован для показа того, что системы, растущие без ограничений, достигают точки, в которой ограничиваются входящие потоки ресурсов, что создаёт необходимость в координации и управлении для эффективного распределения ресурсов.
