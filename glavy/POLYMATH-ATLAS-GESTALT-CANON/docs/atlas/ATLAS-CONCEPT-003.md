# CONCEPT-003: РЕСУРС

## Определение

Ресурс — это входящий поток вещества, энергии, информации или способности, который система захватывает из своего окружения и использует для поддержания своего состояния или расширения. Ресурс является исчерпаемым (в конечный момент времени доступное количество ограничено) и конкурируемым (другие системы могут претендовать на тот же ресурс).

## Неформально

Ресурс — это всё, что система нуждается, чтобы жить и расти. Для организма — это пища и вода. Для города — это энергия, вода, сырьё и трудовые руки. Для компьютера — это электричество и память. Ресурсы ограничены, и конкуренция за ресурсы — один из ключевых факторов, определяющих рост или спад системы.

## Формально

**Поток входящих ресурсов:** для системы S определяется вектор ресурсов R_in(t) = (r₁(t), r₂(t), ..., rₖ(t)), где каждый элемент rᵢ(t) представляет величину i-го вида ресурса, поступающего в систему за единицу времени. Единица измерения — количество вещества или энергии в единицу времени (кг/с, Вт, бит/с и т. д.).

**Поток выходящих ресурсов:** аналогично определяется вектор R_out(t) = (r₁'(t), r₂'(t), ..., rₖ'(t)) — ресурсы, которые система теряет, израсходует или выбрасывает.

**Нетто-поток ресурсов:** R_net(t) = R_in(t) - R_out(t). Если R_net > 0 для некоторого ресурса, то этот ресурс накапливается в системе и может быть использован для роста. Если R_net < 0, система исчерпывает запасы этого ресурса.

**Типы ресурсов:**

- **Материальные (вещественные) ресурсы:** вода, питательные вещества, минералы, топливо. Измеряются в килограммах, литрах, молях.

- **Энергетические ресурсы:** солнечная радиация, тепло, электричество. Измеряются в ватах (энергия в единицу времени) или джоулях (абсолютное количество).

- **Информационные ресурсы:** данные, сигналы, знания. Измеряются в битах, информационной энтропии.

- **Ёмкостные ресурсы:** пространство, время, связность (способность взаимодействовать с другими элементами). Измеряются в единицах протяжённости, временных единиц, количества возможных соединений.

**Запас ресурсов:** система может иметь накопленный запас ресурса R_stock(t), который она может использовать в периоды, когда входящий поток снижается. R_stock(t+Δt) = R_stock(t) + R_net(t)·Δt.

## Типы и различения

**По возобновляемости:**
- Возобновляемые ресурсы: восполняются из окружения быстро (солнечная энергия, пресная вода, древесина в управляемом лесу). Могут быть использованы устойчиво, если скорость потребления не превышает скорость восполнения.
- Невозобновляемые ресурсы: восполняются очень медленно или не восполняются в историческом масштабе времени (ископаемые топливо, редкие элементы, фоссильные запасы воды). Их истощение неизбежно, если они не перерабатываются.

**По критичности:**
- Критичные ресурсы: необходимы для выживания системы. Если поток критичного ресурса падает ниже порога, система может быстро коллапсировать.
- Некритичные ресурсы: способствуют росту, но не являются необходимыми для выживания. Система может функционировать с пониженной производительностью, если они недоступны.

**По конкурентности:**
- Конкурируемые ресурсы: если один агент (система) использует ресурс, другой агент не может его использовать (земля, пища, энергия из одного источника).
- Неконкурируемые ресурсы: несколько систем могут одновременно использовать один ресурс без ущерба друг другу (информация, знания, атмосферный кислород — в пределах его производства).

## Используется в

- **STEP-001:** рост системы возможен только если входящий поток ресурсов превышает выходящий поток. Инвариант роста говорит, что система растёт, если существует положительный нетто-поток ресурсов.
